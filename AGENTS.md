
# Project Instructions

## Plain Writing

For any task involving drafting, rewriting, polishing, or reviewing formal Chinese or English documents, including technical reports, specifications, proposals, academic papers, and README files:

1. Read `.agents/skills/plain-writing/SKILL.md` in full before starting the writing task.
2. Follow the writing rules defined in that file throughout the task.
3. Apply these rules to formal writing tasks only. Do not apply them to ordinary coding, debugging, data analysis, or unrelated conversations.
4. Preserve the original facts, data, technical conclusions, and citations unless the user explicitly requests changes.
5. The user's explicit instructions take precedence over the writing preferences in this skill.
